Browser non supportato

Batch Renamer & File Organizer Pro rinomina i file direttamente nella tua cartella locale usando la File System Access API (window.showDirectoryPicker()). Questa API è disponibile solo nei browser basati su Chromium.

Browser supportati:

  • ✅ Google Chrome (versione 86 o superiore)
  • ✅ Microsoft Edge (versione 86 o superiore)
  • ✅ Opera / Brave (basati su Chromium)
  • ❌ Mozilla Firefox — non supportato
  • ❌ Apple Safari — non supportato

Apri questa pagina in Chrome, Edge, Opera o Brave per continuare.
