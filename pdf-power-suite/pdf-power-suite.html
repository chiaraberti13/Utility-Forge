OCR → Searchable PDF

Recognize text in a scanned/image PDF and embed it as an invisible, selectable text layer.

This is the one feature in PDF Power Suite that needs the internet beyond the initial page load. Recognizing text runs the Tesseract.js OCR engine, which downloads its worker script, WASM core and language data (roughly 10–15 MB per language, cached by the browser afterwards) from a CDN the first time you run it. Every other tab in this tool works fully offline once the page has loaded.
Output: the recognized words are drawn back onto each page as real, selectable/searchable PDF text with opacity: 0 — visually the page looks exactly like the original scan, but you can now select, copy and search its text. Word position and size are matched to Tesseract's bounding boxes; very small or rotated text may end up only approximately aligned, since the goal is searchability, not pixel-perfect invisible glyph placement.

Table Extraction

Heuristically detect a simple grid-like table and export it as CSV.

This is a best-effort heuristic (clustering text by row/column position), not a full table-recognition model. It works well on simple grid-like tables with clear alignment and struggles with merged cells, multi-line cells or unusual layouts. Tune the sliders below and re-run if the first pass looks wrong.
